## behaviors

- **B2** `//go:embed swagger-ui/*` (or `all:swagger-ui`) embeds the vendored Swagger UI static dist (Task 10). | ac: AC-2 | kind: normal
- **B3** `GET /openapi.yaml` → `200 application/yaml` serving the embedded spec. | ac: AC-2 | kind: normal
- **B4** `GET /openapi.json` → `200 application/json` serving the embedded spec. | ac: AC-2 | kind: normal
- **B5** `GET /docs/` → `200 text/html` serving the vendored Swagger UI `index.html` pointed at `/openapi.json` (the UI loads the spec client-side). | ac: AC-2 | kind: normal
- **B6** The swagger routes are PUBLIC (no auth) and sit OUTSIDE the api router's `authMiddleware` — Task 11's `web.Handler` routes `/openapi.*` + `/docs` to this sub-handler BEFORE the SPA fallback (so they do NOT fall through to `index.html`). | ac: AC-2 | kind: normal
- **B7** The swagger sub-handler is wired into the `web.Handler` mux (Task 11 left these paths falling through to SPA; this task inserts the real handler ahead of the fallback). | ac: AC-2 | kind: normal

## invariants

- **INV-spec-is-static:** the served spec is the COMMITTED embedded bytes (regenerated by `make web-build`, Task 14). It is NOT generated at runtime. The Go gate serves it with `swag` absent.
- **INV-public-contract:** `/openapi.{yaml,json}` + `/docs/` are unauthenticated (the API contract + UI load before any token — same public-surface rule as the SPA shell). Do NOT wrap them in `authMiddleware`.
- **INV-no-spec-drift-at-serve:** the served YAML IS the embedded `internal/web/api/openapi.yaml`. There is no hand-editing layer. Drift prevention is the Task-15 route-name probe (re-run `make web-build` to regen).
- **INV-ui-points-at-local-spec:** the Swagger UI `index.html` is configured (via its url param or a vendored override) to fetch `/openapi.json` — same-origin, no CORS.
