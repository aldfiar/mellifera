# Conventions — web-ui Phase 2a

> Anti-patterns, scope rules, and the non-negotiables the coder/QA must enforce.
> Extends the Phase-1 conventions (`docs/web-ui/conventions.md`) + the project's
> `mellifera-build` skill. The Go side follows existing Go conventions UNCHANGED;
> this file governs the NEW React app under `web/`.

## 1. Scope boundary (NON-NEGOTIABLE)

- **ADDITIVE.** Phase 2a touches NO Go source. The only Go-side deltas are (a) the regenerated, committed `internal/web/dist/*` bytes and (b) two doc/build files (`Makefile`, `web/README.md`). `internal/api/*.go`, `internal/web/web.go`, `internal/web/swagger.go`, `cmd/mellifera/main.go`, `proto/`, `pkg/sdk`, `internal/{scan,enrich,store,module,plugin}` are **byte-identical vs `47f276e`** (AC-6).
- **No new API endpoints.** The SPA consumes only existing Phase-1 routes (`internal/api/router.go:89-102`). Adding an endpoint REQUIRES a scope-boundary exception (none foreseen in 2a; if 2b needs one, it gets its own plan). (AC-7)
- **`go.mod`/`go.sum` unchanged.** The React deps are npm (dev/build-only); they NEVER enter the Go module. The Go binary serves only the built, hashed assets.
- **Node is dev-only.** `make build`/`check`/`test`/`lint` NEVER invoke `node`/`npm`/`swag` (operator-runbook §1). `make web-build` is the ONLY node-touching target; it is NOT a prerequisite of any Go gate target.

## 2. Anti-patterns (reject at review)

- **Do NOT round/average/collapse document values.** Ratings, scores, votes render verbatim (`8.9`, not `9`; per arch §3.4/§11.2). No `toFixed`, no `Math.round` on document numbers, no locale-based reformatting that loses precision. (Precision is a structural invariant — arch §11.2.)
- **Do NOT collapse `sources.<plugin>` namespaces.** Per-source values coexist forever (arch §3.1 Tier 2). The UI renders each plugin's namespace; it never merges `sources.tmdb.ratings.score` with `sources.kinopoisk.ratings.score`.
- **Do NOT trust the token for data.** The SPA's `RequireAuth` checks presence-of-token for routing only. The Go `authMiddleware` + `requireRole` are the sole authZ authority (`middleware.go:32-75`). A 401 from `/api` is the source of truth — clear the token, redirect to `/login`.
- **Do NOT add a Go login/cookie endpoint.** The admin token is a static env var (`MELLIFERA_ADMIN_TOKEN`, `main.go:240-244`); MVP auth = the SPA sends it as Bearer. A cookie/session endpoint is D18 (multi-user), out of scope.
- **Do NOT change the embed directive or `web.Handler`.** `//go:embed all:dist` (`web.go:20`) and the routing/cache logic are Phase-1-stable. Phase 2a only changes the BYTES in `dist/`. If a Go change seems needed, STOP — it's out of scope (escalate).
- **Do NOT emit the build to `web/dist/`.** The embed target is `internal/web/dist/` (package-local — embed paths cannot escape `internal/web`). `/web/dist/` is gitignored and unused. Vite `outDir` MUST be `../internal/web/dist`.
- **Do NOT introduce runtime CDNs.** All JS/CSS is bundled into the hashed assets at build time. The binary serves a self-contained SPA (no external script/style fetches at runtime).
- **Do NOT hand-edit `internal/web/dist/*` or `internal/web/api/openapi.*`.** These are regenerated by `make web-build` (like `*.pb.go` are regenerated by `proto`). Drift = review FAIL.

## 3. Naming / layout (React app under `web/`)

- **npm project root:** `web/` (per `web/README.md:66-81`). NOT `internal/web` (the Makefile comment at `Makefile:61` is wrong — R1).
- **TS path alias:** `@/*` → `src/*` (vite + tsconfig resolve).
- **Files:** `kebab-case` for non-component files (`lib/api.ts`, `pages/admin/libraries-status.ts`); `PascalCase.tsx` for React components (`RequireAuth.tsx`, `Login.tsx`, `Libraries.tsx`).
- **Hooks:** `use<Thing>` (`useLibraries`, `useToken`). TanStack Query keys: `["libraries"]`, `["admin-status"]`, `["library-scan", id]`.
- **DTO types:** mirror the Go DTO field names verbatim (`module_id`, not `moduleId`) — they ARE the JSON wire shape (`internal/api/handlers.go`). Drift = bug.
- **shadcn primitives:** live under `web/src/components/ui/` (copy-in; version-pinned in `package.json`).

## 4. Auth posture (XSS acknowledged, accepted for MVP)

- **Threat model:** a personal media server, bound to `127.0.0.1` by default (`MELLIFERA_LISTEN`, `main.go:251`). The operator is the single user. The SPA shell is static + same-origin; the only third-party JS is the committed, hashed build (Radix/TanStack/Tailwind — bundled, not runtime-fetched).
- **Token in localStorage:** readable by any JS running in the SPA origin (XSS). Accepted for MVP because (a) the origin is localhost/private, (b) no untrusted user content is rendered as HTML in 2a (all metadata rendering in 2b is text/structured, not `dangerouslySetInnerHTML`), (c) a stolen token = full admin (already the MVP posture per arch §11.5). **2b MUST NOT use `dangerouslySetInnerHTML` for document values** — render as text/structured children only.
- **Public surface unchanged:** `/`, `/assets/*`, `/openapi.*`, `/docs` stay unauthenticated (R-2; operator-runbook §3). All data stays behind `/api/v1/*`. Phase 2a adds NO new public data.
- **Revisit at D18:** real multi-user auth (sessions, httpOnly cookies, ACLs) replaces localStorage — arch §11.5 grounds this as additive (Principal + resolvers, not an API rework).

## 6. Build / dev workflow

- **Dev:** `MELLIFERA_WEB_DEV=true MELLIFERA_ADMIN_TOKEN=dev-token go run ./cmd/mellifera` (:8080) + `cd web && npm run dev` (:5173). Vite proxies `/api`+`/openapi.*`+`/docs` → :8080. `MELLIFERA_WEB_DEV=true` loosens Go cache headers so Vite hot-reload isn't masked (`main.go:255`).
- **Build (dev/CI):** `make web-build` → `cd web && npm ci && npm run build` → `internal/web/dist/{index.html,assets/*}` (committed). Then `make build && make check && make test` (node-free) verifies the Go gate embeds the real build.
- **Commit the dist.** `internal/web/dist/*` is committed (NOT gitignored) — it's the embed INPUT. Regenerate via `make web-build` after any `web/src` change, then commit the new bytes (mirrors committing regenerated `*.pb.go`).
- **Go gate (node-free):** `make build && make check && make lint && make test` on a host without node → exit 0 (AC-6).

## 7. Testing posture (Phase 2a)

- **JS unit (Vitest):** `lib/api.ts` (Bearer attached; 401 → token cleared + redirect; canonical error parse), `lib/auth.ts` (token storage round-trip), `<RequireAuth>` (redirect-when-absent). Co-located `*.test.ts(x)` under `web/src/`.
- **Structural probes (AC-5/AC-6/AC-7):** the `curl` verify probes in `acceptance.md` (served HTML references hashed assets; Go gate node-free; no off-contract API calls; INV2 import check).
- **No new Go tests required** (Go source unchanged). The existing `internal/web`/`internal/api` tests still pass against the real React dist (they assert headers/fallback/routing, not placeholder bytes — the specifier verifies this holds; if a test hard-codes placeholder bytes, it's a Phase-1 test gap to flag, NOT a Go source change in 2a).

## 8. Invariants inherited (do not break)

- **INV1** (api pure delegation), **INV2** (api no plugin/enrich/module/web import), **INV5** (api 7 symbols) — all hold trivially (no Go change). Cited in `internal/api/doc.go`.
- **R-2** (public static surface; data behind `/api/v1/*`) — preserved (Phase 2a changes only the bytes served at the public surface, not the auth model).
- **Single-binary + pure-Go/no-CGO at runtime** — preserved (the SPA is embedded assets; node never in the Go build).
