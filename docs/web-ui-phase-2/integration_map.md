## Behavior-change impact on existing flows

- **The public SPA surface stays public.** `/`, `/assets/*`, `/openapi.*`, `/docs` remain unauthenticated (R-2 from Phase 1; `web/README.md`, operator-runbook §3). Phase 2a only changes the BYTES served at `/` + `/assets/*` (placeholder → React build) — the auth model is unchanged. All data stays behind role-gated `/api/v1/*` (`router.go:89-102`).
- **Cache headers unchanged.** Hashed `/assets/*` → immutable; index → no-cache (`web.go:97-102`). The React build's hashed filenames fit the existing `serveAsset` path (`web.go:79-93`) — Vite hashes filenames, preserves extensions, so `contentTypeFor` (`web.go:108-133`) maps them correctly. No Go change.
- **SPA client-side routing** relies on the Phase-1 NotFound fallback (`web.go:54-63`): any non-`/api`/`/openapi`/`/docs`/`/assets` path serves `index.html` (200). `/admin`, `/login` work without server config. Broken hashed assets still 404 fail-fast (`web.go:58-60`).
- **The Go build gate is unchanged in mechanism.** `make build`/`check`/`test`/`lint` embed committed bytes and never invoke node (operator-runbook §1). The only delta: the committed `internal/web/dist/*` bytes are now a Vite build instead of a placeholder.

## External boundary changes

Phase 2a introduces NO new external calls from the Go binary. The SPA (in the operator's browser) makes same-origin `/api/v1/*` calls to the Go server that serves it. No third-party APIs, no outbound HTTP from Go, no new DB access.

- **Timeout/retry/idempotency:** TanStack Query provides client-side retry (default 3 with backoff) for failed `/api` GETs; mutations (`POST /libraries`, `POST /scan`) are NOT auto-retried (non-idempotent — the operator re-clicks). The Go side applies no per-request timeout beyond `ReadHeaderTimeout` (`main.go:59`). N/A for external boundaries (there are none new).
- **The Vite dev proxy** (S3) is dev-only; production serves the embedded build — no proxy at runtime.
