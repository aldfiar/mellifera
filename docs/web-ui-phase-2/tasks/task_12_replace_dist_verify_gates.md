- **INV-dist-index-html:** `internal/web/dist/index.html` MUST exist after `make web-build` (else `mustReadIndex` panics at init — `internal/web/web.go:138-144`). Vite emits it by default (R5).
- **INV-node-free-gate:** the Go gate (`make build && make check && make lint && make test`) NEVER invokes node. It embeds the committed bytes. `make web-build` is run BEFORE the gate, separately, to produce those bytes.
- **INV-go-source-byte-identical:** `git diff 47f276e HEAD -- internal/api internal/web/web.go internal/web/swagger.go cmd/mellifera proto/ pkg/sdk internal/scan internal/enrich` → EMPTY. Only `internal/web/dist/*` bytes + `web/` + `Makefile` + `web/README.md` changed (AC-6).
- **INV-no-hand-edit-dist:** the dist bytes are GENERATED by `make web-build` only. Do NOT hand-edit `internal/web/dist/*` (conventions §2).
