## Notes / carve-outs

- **AC-4 / AC-1 structural source-text probes** are the task-mandated (task_13 `INV-automated-probes`) carve-out from the code-quality "no source-text assertions" rule. They guard NEGATIVE architectural invariants with no runtime expression (media logic must stay out of core; parseTV must stay out of base-scanner); source inspection is the only durable guard, and check.sh does NOT enforce them. The AC-4 probe is verified non-tautological (the same quoted-literal probe finds the sanctioned literals in `internal/module` seed config while reporting 0 in the orchestrator).
- **Reviewer-independence (golden rule):** QA-1 does NOT trust the coder's `integration_pipeline_test.go`. It re-derives expected outputs from a DIFFERENT fixture set via a hand-authored table (`qppTVExpectations`), not via the coder's `ipDeriveShow` or the plugin's `parseTV`.
