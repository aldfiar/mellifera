## Anatomy law (EpisodeCard)

- 16:9 still (`STILL_ASPECT`) → title clamp-2 at `typeSmall()` → duration at
  `typeMeta()`; the ✓ corner mark and the in-progress bar render ON the still
  (the card law's tri-state: watched → ✓ and NO bar; in-progress → bar and NO
  ✓; absent → neither — `watchedPercent`'s null law stands).
- Field-driven law untouched: absent artwork renders the S-2 fallback in the
  fixed-aspect art box; absent title/duration render absence.

## Data law

- Episode title: the served document's `title` field when present (same
  read-time document accessor family as `documentDuration`), else the
  composed name — NEVER re-derived client-side. Pure and JVM-pinned
  (`episodeTitle(document, displayName)`).
- Duration: the existing `documentDuration` read; absent → no duration line.

## Grid law

- Columns: the «Эпизодов в ряду» pref via `LocalGridPrefs` — null = Авто →
  `gridPlan` with the hero chrome reserve; 2 / 3 / 4 override.
- Navigation: the same dpad walker law the poster grid uses
  (`moveInGrid`-family; `dpad/KeyRouting.kt` untouched — the series page
  consumes the existing law); an arrow the law cannot satisfy stays
  unconsumed.
- Initial focus: the first unwatched episode when the served rows carry
  watched states, else index 0. The law's HOME is `nav/InitialFocus.kt`:
  `browseFocusTarget` (`FocusTarget.EpisodeRow` :53) computes/keeps the
  first-unwatched focus for the grid — the target is retained or renamed
  (e.g. `EpisodeGrid`) and the `FocusLawTest::every_screen_resolves_initial_focus`
  pin updates with it (the law lives there, not only in this contract).
- BACK = the series grid (the BackHandler chain unchanged); the hero takes no
  dpad focus; bottom grid padding = `PARITY_OVERSCAN_Y`.
- OK plays (the 2026-11-12 dead-OK defect stays fixed — `EpisodesTest`
  guards).

## Call-site law

- `BrowseScreen.kt`: SeriesPage swaps the episode list for the grid;
  EpisodeRow's remaining uses (if any outside this page) stay — the retirement

  `browseFocusTarget` serves the episode grid's first-unwatched focus; the
