# Tasks: design (element & library management UI)

Four groups, strictly SPA-only (zero Go source changes): Pass 1 filenames +
CardActions shell → Pass 2 Identify/Refresh views → Pass 3 library Manage
overlay → Landing. Group dependencies: 1 → 2 → 3 → 4 (Pass 2 and Pass 3 both
mount views into the Pass-1 shell; Pass 3 lifts that shell). Probes run from
the repo root; web probes use the `cd web && npx vitest run <file>` shape.
Every scenario lives in the web-ui spec delta; each box links the probe of
its primary scenario — the remaining scenario probes in the delta are
re-run at the gate by the reviewer. No qa group: the change is SPA-only
against shipped endpoints (the one cross-language contract, the naming
mirror, is pinned by golden-vector probes inside group 3).
