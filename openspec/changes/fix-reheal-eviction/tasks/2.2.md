# 2.2 Budget stale-first precedence — retained builds never shield from the cap

## Goal

When the artifact budget demands space, a retained superseded directory is
reclaimed before any current build — ahead of watch recency, regardless of
its grace — because reclaiming a superseded directory unpublishes nothing
while reclaiming a current build forces a re-pack (the evict-heal churn
loop the frontier pin exists to break).
