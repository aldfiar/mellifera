# 5.1 App scaffold (android/) — replaces and deletes the T0 probe

## Goal

The real `android/` module: single Gradle module, Kotlin + Compose for TV +
Media3/ExoPlayer + Coil, minSdk 23, carrying the minimal-architecture
skeleton (design D1) so every later 5.x task lands in a shaped home — and
DELETING android-tvprobe/ entirely (the throwaway probe from 1.2; its
evidence already lives in tasks/1.3.md and needs no code).

## Removal map

- DELETE `android-tvprobe/` (every file): created by task 1.2 as a throwaway,
  explicitly superseded by this scaffold. Readers probed: tasks/1.2.md (the
  probe contract — consumed), tasks/1.3.md (the on-device evidence — already
  extracted, lives in the change folder). No source outside the probe
  references it. `.dockerignore`'s android-tvprobe/ entry (task 4.1) becomes
  a harmless no-op and stays (a rebuild between 4.1 and 5.1 needs it).
- KEEP `.gitignore`'s android-tvprobe/ entries: harmless, and deleting them
  here would churn a shared file for zero effect.

## Context pointers

- design: D1 (minimal branch, split trigger, seam), D6 (signing law), D8
  (PlayerController seam contract — the interface the scaffold declares)
- tasks/1.3.md: T0-RESULT Compose viability — read BEFORE committing the UI
  stack; a falsified Compose re-opens design (OQ-T4), never silently swaps
- versions: pinned at scaffold time (AGP/Gradle/Kotlin/Compose-TV/Media3/Coil),
  JDK 17 toolchain fixed; versionName/versionCode from -P props with dev
  defaults (D4 — the FILENAME carries the version: mellifera-tv-<version>.apk)

## Done when

- `android/gradlew -p android assembleDebug testDebugUnitTest` exits 0
  (the duty): the module builds a debug APK and runs JVM unit tests.
- Module shape present: MainActivity + `App()` when-screen shell,
  `AppViewModel` + immutable `AppState` skeleton, `net/` stub (full client
  lands in 5.3), `player/PlayerController` interface per design D8,
  `ui/Focus.kt` placeholder, `state/` package ready for the machine (5.5).
- minSdk 23; `android:usesCleartextTraffic="true"`; NO nav library, NO DI
  framework (D1).
- Version plumbing: `-PversionName= -PversionCode=` flow into the manifest
  with dev defaults; `assembleRelease` FAILS LOUDLY without
  `android/keystore.properties` (D6 signing law — debug-signed release
  shipped once blocks updates on that TV forever); debug fallback confined
  to `assembleDebug`.
- `tv.mellifera.AppSmokeTest::app_state_initializes` passes (JVM): the
  AppState initializes to the first-run screen with no stored state.
- android-tvprobe/ is gone from the tree.

## Audit

Not an audit task. Signing-law audit note for GATE 2: the keystore-failure
path (assembleRelease without android/keystore.properties fails loudly) has
NO automated green receipt by design — a deliberately-failing gradle run as
a duty is noise. The reviewer inspects the signing block by audit; the
positive path is exercised by 5.2's real release run.

## Out of scope

- Screens beyond the shell (pairing 5.4, browse 5.6), the flow machine (5.5),
  the Media3 controller impl (5.7), keystore GENERATION (5.2's body).
- Any server or SPA file.

## Handoff

- 5.2 consumes the -P prop plumbing + signing law for the real release run.
- 5.3-5.11 land their code in the packages this scaffold fixes; the
  PlayerController interface declared here is 5.7's implementation contract.
