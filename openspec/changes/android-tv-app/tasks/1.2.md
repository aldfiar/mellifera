# 1.2 Throwaway T0 probe app (android-tvprobe/)

## Goal

A minimal single-Activity ExoPlayer probe, NO Compose, that assembles a debug
APK on this Mac and runs the four device-risk probes on the real TV box
(executed by task 1.3). It gates D1/OQ-T1..T4 before ANY real app work and is
DELETED by task 5.1's real scaffold. It lives at repo root `android-tvprobe/`,
NOT under `android/` — the new-module qa mandate never binds here.

## Context pointers

- design: design.md D1 (why the probe precedes the scaffold), OQ-T1..T4
- environment facts: JDK 17 present (Corretto 17.0.11), adb present, NO
  Android SDK until task 1.1, no gradle on PATH — the wrapper bootstrap may
  brew-install gradle once in this task's body
- probe targets: the four proven TV failure classes
  (.tmp/android-tv-app-design.md §Why) — HEVC remux HLS, MKV original,
  translated multi-EXT-X-MAP HLS, backgrounded media keys

## Done when

- `android-tvprobe/gradlew -p android-tvprobe assembleDebug` exits 0 on this
  Mac (JDK 17 toolchain; ANDROID_HOME default location from task 1.1).
- The probe app: minSdk 23, cleartext allowed (plain-http LAN server), one
  fullscreen surface with one button per probe stream (URL pasted via
  adb/on-screen), ExoPlayer renders into a SurfaceView, media keys control
  playback, player errors surface on-screen (the probe answers questions,
  it is not a product).
- `.gitignore` gains android-tvprobe/build, android-tvprobe/.gradle,
  android-tvprobe/local.properties (the wrapper generates the last).
- Nothing outside android-tvprobe/ and .gitignore is touched.

## Audit
