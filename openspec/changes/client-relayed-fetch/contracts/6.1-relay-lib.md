# Contract — task 6.1 (relay client core)

## Task

- **Id / Title:** 6.1 — Add web/src/lib/relay.ts: claimOnce, executeDescriptor, postResult — a pure module, table-driven vitest with a mocked fetch. @qa
- **Duty:** `cd web && npx vitest run src/lib/relay.test.ts && grep -q 'executeDescriptor' src/lib/relay.ts || exit 1`
- **Downstream:** task 6.2 (the hook drives this module), task 7.2 (the build carries it).

## Scope

**In:**
- `web/src/lib/relay.ts` (new — the pure core)
- `web/src/lib/relay.test.ts` (new — table-driven vectors)

**Out:** every component and page, `web/src/lib/api.ts` (the fetch wrapper is imported, never edited), `web/src/lib/queries.ts`, the whole Go tree.

## Design pins

- The descriptor is executed VERBATIM (web-ui delta): served method/url/headers are never modified, never re-derived, never "fixed up" client-side — the byte-identical Go contract posture the allowlist requirement pins.
- `timeout_seconds` aborts via AbortController; redirects follow (the fetch default — parity with `http.DefaultClient`); `min_interval_ms` paces between executions best-effort (module-level last-send bookkeeping).
- postResult posts `{http_status, headers, body(base64 when binary_safe), error}` — a non-2xx fetch is still a POSTED outcome (the transport worked; the upstream failed); only transport-level failure (abort, network) posts error-only.
- claimOnce rides the authenticated fetch wrapper (the bearer header); a 204 decodes to "nothing to do" without throwing.
- Russian copy: none — this module renders nothing.

## Acceptance

- The duty exits 0: the vitest vectors green with a mocked fetch.
- Vectors assert: descriptor fields out verbatim, base64 body under binary_safe (raw under its absence), timeout abort posts the error outcome, 204 claim is a no-op.

## Constraints

- No React imports — the module stays testable as pure functions (the nextup.ts precedent).
- The allowlist: the only URLs this module touches are `/api/v1/relay/claim` and `/api/v1/relay/{id}/result` plus the descriptor's own served url.

## Handoff

- 6.2's hook calls claimOnce/executeDescriptor/postResult on its interval — this module's exports are its whole surface; the descriptor type here is the wire contract 4.1 serves.
