# Contract — task 4.1 (cross-module golden joints)

## Task

- **Id / Title:** 4.1 — Committed golden fixtures pinning the two served contracts, read by BOTH suites (authored for @wf-qa). @qa
- **Duty:** `go test ./internal/api -run TestWatchDefaultsGolden -count=1 && go test ./internal/stream -run TestSectionsGolden -count=1 && cd web && npx vitest run src/lib/skipSections.test.ts src/lib/queries.test.tsx || exit 1`
- **Downstream:** none — this task IS the layer's Tier 1 joint record.

## Scope

**In:**
- `internal/api/testdata/golden/watch_defaults.json` (new fixture)
- `internal/api/watchdefaults_golden_test.go` (new — `TestWatchDefaultsGolden`)
- `internal/stream/testdata/golden/sections_chapters.json` (new fixture)
- `internal/stream/sections_golden_test.go` (new — `TestSectionsGolden`)
- `web/src/lib/queries.test.tsx` (golden consumer block: watch defaults wire contract)
- `web/src/lib/skipSections.test.ts` (golden consumer block: sections → classification)

**Out:** handler and implementation changes (1.1 / 3.1 / 3.3 own those — a joint failure means fixing the producer or the fixture through its OWNING task, never bending a fixture here silently), every other package.

## Design pins

- ONE committed fixture file per joint, read by both suites — the naming-golden precedent: `internal/api/testdata/golden/title_vectors.json` pinned by `TestGoldenTitleVectors` and resolved from `web/src/lib/naming.test.ts` via a relative path.
- `watch_defaults.json` pins the wire BODY `{"auto_next_countdown_seconds": <int>}`: the Go producer test asserts the handler writes exactly the fixture shape with the fixture value wired into Deps; the vitest block asserts the client parses the same bytes into the same value.
- `sections_chapters.json` pins REAL chapter projections (intro/credits/opening variants, an unclassified title, an end-less section): the Go test asserts `projectChapters`' output matches the fixture; the vitest block asserts `skipSections` classifies each golden section to the expected chip — or to none.
- One-sided drift fails by construction: changing a producer without the fixture (or the fixture without the consumer) breaks the other suite.

## Acceptance

- Both Go golden tests green; both vitest golden blocks green (the duty).
- The joints hold with real instances, no mocks (Tier 1): api's served body satisfies the web client's contract; stream's projection satisfies the chip classifier's contract.

## Constraints

- The Go gate stays node-free — fixtures are committed data, never a build step.
- Fixtures live under the Go packages' testdata convention; vitest resolves them via relative paths (the naming.test.ts pattern).

## Handoff

- If a golden fails at GATE 2, the fix is a new decision through the owning task — never a silent fixture edit.
- The fixtures are the durable cross-module contract record once the machine home is gone.
