# 1.1 PackGate transcode arm — the judge opens the HEVC class under the knob

## Goal

One gate arm: while `MELLIFERA_STREAM_TRANSCODE` is on, an `opt_in`-class
item whose video stream is HEVC is packable on every seam — same judge,
same refusal tokens, no new vocabulary — and knob-off answers are today's
answers byte for byte.
