## Design pins

- Card: «Следующая серия» naming the next episode (series served display title, SxxEyy label, served episode title when present) with [Смотреть] / [Отмена]; renders on the ended edge of EPISODES ONLY (parsed facts present) — films never render it.
- Next pick: `nextEpisodeAfter` from `lib/nextup.ts` (task 2.2) — no second derivation anywhere.
- Countdown (Q5): the duration comes ONLY from the served shape `auto_next_countdown_seconds` via `useWatchDefaults`; reaching zero navigates into the next episode. Shape unavailable (loading or failed) → card renders without a countdown and NEVER autoplays (design.md D5) — no client fallback value.
- Cancel (Q6): [Отмена] stops the countdown and suppresses the card for the rest of the browsing session via the `sessionStorage` key `mellifera.autoNextCancelled` (design.md D4 — survives reloads, dies with the tab). localStorage is REJECTED; the durable per-user flag is Layer 6.

## Constraints

- The sessionStorage key is written and read only inside the AutoNext module (design.md Interfaces) — no other module touches it.
