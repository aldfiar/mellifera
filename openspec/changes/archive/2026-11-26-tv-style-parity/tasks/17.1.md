## Function law

```
trackFromHeight(rows) = ((H − chrome − rows × caption) / rows) × aspect
columnsAuto           = floor((W + gutter) / (trackFromHeight + gutter))
columns               = columnOverride ?? columnsAuto
track                 = min((W + gutter) / columns − gutter, trackFromHeight)
tier                  = 2 rows when track ≥ 110dp (poster width floor), else 1 row + peek
```

- W = the content column width (0.92 × screen − the overscan edges;
  ≈883dp at 960dp), H = the viewport height (540dp at the reference shape),
  aspect = width/height (`POSTER_ASPECT` 2/3, `STILL_ASPECT` 16/9,
  `PHOTO_TILE_ASPECT` 1f), gutter = `PARITY_GUTTER` 6dp.
- `chromeReserve(mode, surface)` / `captionReserve(mode, surface)`: REGULAR
  serial inputs are the draft's RULED numbers — chrome 80dp (title 28 + chips
  36 + gap 16), caption 58dp (2-line title 28 + Season chip 24 + gap 6).
  COMPACT/LARGE calibrate so the pinned outputs below reproduce; the test
  table wins over any input derivation (the precedence rule).
- Surface map: POSTERS (serial 2:3), STILLS (tv 16:9 — no special case, Q6
  default), PHOTOS (1:1, «Авто» = 4), HOME (16:9, 4 across), EPISODES
  («Эпизодов в ряду», Авто = 3 with the ~100dp hero chrome reserve at
  Обычный).
- The override (4..7 posters / 2..4 episodes) replaces the auto count and is
  clamped by the formula — a caption never clips (the override grows the peek
  or the track shrinks, never the caption).
- The override travels as `Int?` on the prefs flows (null = Авто) — the grid
  call sites read `LocalGridPrefs` + `LocalUiScale` and pass them in.
