# 2.1 Codecs recorded at publish — probe the init segments, compose RFC 6381

## Goal

A published build carries its true codec description: `Pack` probes each
distinct `EXT-X-MAP` init segment with ffprobe and composes the RFC 6381
codec strings through one pure table; `Build` carries them (video first,
then audio in the pinned rendition order, deduped). This is the recorded
half of the descriptor's `codecs` field (task 2.2 projects it).

## Context pointers

- design: design.md D2 (why the artifact is probed, not the source; the
  admitted families; the fail-open degradation), Interfaces (the persisted
  record's order), Open Question 2 (the per-family constants — including
  the hvc1/hev1 sample-entry choice — are this task's judgment, table-
  tested)
- code: `internal/stream/pack.go` — `Pack` (`:46`, the once-per-run entry
  that returns `Build`), `packInto`/`publishHeadOnly` (`:129-186`, the
  publish points where the init segments exist on disk in final form),
  `variantLayout` (`:83`, the per-variant init naming the probe must
  resolve); the composition table is a new pure function + table in the
  stream package (shared with 2.2's read-side legacy composition — one
  table, two callers); `runFFmpeg` (`:350`) is the exec precedent (ffprobe
  execs beside it; ffprobe ships with ffmpeg)
- families: avc1, hvc1/hev1, mp4a.40.2, opus, flac, ac-3, ec-3, mp3,
  vorbis — exactly the classifier's admitted set
  (`internal/stream/classification.go:51-77`); a probe fact outside the
  table degrades the whole record to absent (fail-open)
- specs: packaged-playback delta "Playback descriptor and verb split" —
  scenario "Packaged descriptor carries the pack's codecs" (2.2 serves it;
  this task makes the record true)

## Done when

- `go test ./internal/stream -run TestPackCodecs` passes: a real pack of a
  generated h264+AAC fixture publishes with `Build.Codecs` carrying one
  avc1 entry first and the mp4a.40.2 entry — cross-checked against ffprobe
  of the same published init segment inside the test (the artifact is the
  oracle); a multi-rendition build (voiceover sidecar) lists the embedded
  audio before the sidecar's codec, per the pinned rendition order.
- The table is table-tested per family (pure function cases — no ffmpeg):
  each admitted codec_name/profile composes its documented string; an
  unknown codec_name degrades to absent.
- `go test ./internal/stream -run TestPackLane` stays green (no publish
  behavior change beyond the new field).

## Audit

Not an audit task.

## Out of scope

- Projecting codecs onto the descriptor wire (task 2.2).
- The read-side legacy composition's Describe wiring (task 2.2 — the pure
  table this task lands is its only dependency).
- Manifest CODECS attributes (design Open Question 1 — deliberately not a
  task).

## Handoff

- If a family's composition proves ambiguous in the wild (a profile the
  table maps wrongly), degrade to absent rather than guessing — a skipped
  probe is today's behavior; a wrong probe refuses a capable device.
