Deliver the entity-grain derivation layer for the home rail — entities built
from the caller's progress facts, scored through the existing scorers,
ordered by the entity-grain comparator — pinned by tests, without yet

## Done when

- `go test ./internal/api -run 'TestHomeRoute'` exits 0 (the new entity-level
  subtests green; every existing subtest still green — the route composition
  is untouched, so no existing pin moves)
- entity grouping: rows with parseable episode facts group by
  (libraryID, seriesPath); a multi-row series yields ONE entity; fact-less
  rows stay per-item film entities
- started-max spans ALL touched rows including ledgered ones; resume-max
  skips ledgered rows (skip-ahead case: resume-max < started-max)
- serve-law survival: entity survives iff an in-progress row exists OR
  homeNextPick finds a next; caught-up-without-next yields NO entity;
  ledgered films/tv items yield NO entity
- unresolvable series (missing/tombstone in the namer's SeriesByPath) floors
  to the per-item honest entity (series fields empty, no next)
- entity scoring: serial entities through scoreSeries with the eps map
  UNIONED with the entity's touched items — a drift case (touched item absent
  from the raw eps list) still scores resume ≥1000; films through scoreItems;
  score-shape pin: BOTH the scoreItems-form and the scoreSeries-form are
  asserted for a single-row series, never their equality (the +500
  NewEpisode divergence is order-preserving)
- entity ordering: score desc, then entity max touched-row updated_at desc,
  then ser_/itm_ id floor — a total, deterministic order

## Audit (the task carries `audit: true`)

Read the serve-law prose against the code: survival computed from the SAME
pick result the row serves (not a second derivation); the Q2 union
rationale (document drift) and its documented residual corner (an eps row
with a foreign parsed anchor); the pre-cut QueryItemsBySeries posture vs the
anti-N+1 batched-read rule (D7 — the same full-set-read posture as
allFilteredItems); the honest floors (Q1 per-item fallback, tombstone floor)
never fabricate series identity. Accept when each law is pinned by a named
subtest, not just asserted in prose.
