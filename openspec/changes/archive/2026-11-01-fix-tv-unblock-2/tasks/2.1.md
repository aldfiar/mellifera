# 2.1 Descriptor layout field end-to-end

## Goal

The hls descriptor carries the additive `layout` field
(`single-variant` | `rendition`), persisted at publish, threaded through
Describe to the wire — the one field the SPA refusal (2.2) reads. Legacy
builds answer without it (fail-open); the decision line keeps its pinned
shape.

## Done when

- A rendition build's descriptor answers `layout: "rendition"`; a
  single-variant build's answers `"single-variant"`; both keep `codecs`
  behaving exactly as pinned.
- A namespace predating the record answers no `layout` field and the
  play_url unchanged (fail-open); a direct answer never carries it.
- `Describe`'s test call sites adapt mechanically (the 9th return — the
  codecsSrc precedent, task 4.2 of pack-manifest-audio).
- The decision line is byte-unchanged: one INFO line per GET naming
  item/mode/state/reason/codecs_src — no codec strings, no token, no new
  fields (INV4 holds).

  describe test files, adapt, do not re-design the signature).
- The layout value must be the lane's `layoutName` vocabulary verbatim —
  `single-variant` | `rendition` — the SPA string-compares it.
