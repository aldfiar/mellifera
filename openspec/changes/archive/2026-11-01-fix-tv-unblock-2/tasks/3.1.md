# 3.1 Joint over real fixtures — the composed shape the SPA contract needs

## Goal

One real two-embedded-audio pack, served end-to-end, proves the whole
contract the two groups built: the descriptor names the layout, the
master composes the MSE-safe audio group (unique NAMEs, exactly one
DEFAULT=YES), and the amended pins hold behind it.

## Context pointers

- design: design.md Interfaces 1, 4–6 (the descriptor field, the DEFAULT
  rule, the mapping, the refusal — this task observes all four over real
  instances, no mocks)
- fixtures: `internal/stream/pack_multi_audio_test.go` —
  `makeTwoAudioFixture` (the h264 + aac ×2 MKV generator; the joint test
  mirrors its shape in the itest harness)
- code under joint: the real pack lane (internal/stream), the real
  success persist (internal/enrich), the real descriptor closure
  (cmd/mellifera's Describe path), the build-root master bytes
- pins re-anchored behind the joint duty: the Go repro
  (`TestPackMultiAudioRenditionLayout`) and the Player lane-selection
  suite (`Player.test.tsx` — the refusal green, the re-based flat pin
  green)

## Done when

- `TestTvUnblockJoint` (internal/itest): packing the two-audio source
  through the real lane, then fetching the descriptor through the real
  closure, yields an hls answer carrying `layout: "rendition"` (beside
  `codecs`) and a build-root master with exactly ONE EXT-X-STREAM-INF
  video variant whose EXT-X-MEDIA group carries both embedded audio
  renditions with unique NAMEs and exactly ONE DEFAULT=YES; the
  namespace records `master: 2`.
- The amend-covered pins run green in the same duty: the Go repro and
  the Player suite (refusal + re-based flat pin).

## Out of scope

- Any new production code (the joint observes only; gaps found here go
  back to the owning task, never patched in the joint).

- The joint must not seed or mock the namespace records — the persist
  must write them (that IS the contract: publish → persist → descriptor).
- If the descriptor answers no layout field, check the wave first: a
  freshly packed build carries it immediately; only pre-record builds
  omit it.
