# Tasks: enrichment

Six groups: shikimori plugin → core (anchoring + fetch, re-enrich) → api
admin surface → serial seed + cmd wiring → qa/gates. Dependency DAG:
groups 1, 2, 3 are mutually independent; group 4 needs group 3 (the
refresh route drives `ReenrichSource`); group 5 needs groups 1–4; group 6
needs group 5. Probes run from the repo root and stay node-free; no probe
ever touches the network — shikimori.io is only ever faked (httptest stub
upstreams, fixture payloads).
