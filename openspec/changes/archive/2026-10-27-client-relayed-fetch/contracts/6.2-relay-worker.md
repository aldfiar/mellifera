# Contract — task 6.2 (relay worker hook and shell mount)

## Task

- **Id / Title:** 6.2 — Add web/src/lib/relayWorker.ts with the useRelayWorker hook (~15 s poll, idle backoff, 401 stop, unmount cleanup) and mount it once in web/src/App.tsx's authenticated shell. @qa
- **Duty:** `cd web && npx vitest run src/lib/relayWorker.test.tsx && grep -q 'useRelayWorker' src/App.tsx || exit 1`
- **Downstream:** task 7.2 (the build carries the mounted loop); the loop serves every authenticated session from here on.

## Scope

**In:**
- `web/src/lib/relayWorker.ts` (new — the hook)
- `web/src/lib/relayWorker.test.tsx` (new — interval/backoff/401/unmount vectors)
- `web/src/App.tsx` (one mount call inside the authenticated shell — touch nothing else)

**Out:** every other page and component, `web/src/lib/relay.ts` (6.1's module is consumed, never edited), the Go tree.

## Design pins

- ONE hook instance per authenticated session, mounted in the shell — not per page (a mount inside a page would stop on navigation and multiply polls across tabs' routes).
- Poll cadence ~15 s; idle backoff lengthens the interval between consecutive empty (204) polls and resets to ~15 s the moment a job is claimed (web-ui delta scenario).
- A 401 from any poll STOPS the loop for good — the existing api-wrapper 401 path owns the credential clear and redirect; the hook only stops (no duplicate redirect logic).
- Unmount clears the timer (no stray polls); unauthenticated routes never start the hook (the mount sits inside the authenticated shell, beside RootGate/RequireAuth's covered tree).
- The hook runs concurrently with user actions — no await-blocks-the-UI, no interception of identify search fetches (the search relay interleave is server-side).

## Acceptance

- The duty exits 0: the hook vectors green, the mount present in App.tsx.
- Vectors assert the cadence table (15 s → backoff → reset), the 401 stop, and the unmount cleanup (fake timers; the mocked relay module from 6.1).

## Constraints

- The mount diff in App.tsx is minimal — a hook call in the shell component; route tables and gates untouched (the SPA token authentication requirement keeps its exact behavior).
- React Query is not involved: this is a plain interval hook, not a query (the queue has no cache semantics for the client).

## Handoff

- The gate reviewer pairs this with 6.1's vectors as the client story; 7.2's rebuild carries the mounted loop into the committed dist.
