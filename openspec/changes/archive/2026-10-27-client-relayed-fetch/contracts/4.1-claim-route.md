## Scope

**In:**

## Design pins

- The route mounts in the BROWSE group (admin+client): any authenticated principal is a relay principal (ruled OQ-1); the group is the only gate — the handler never forks on Role.
- Deps.RelayClaim is nil-safe (503 when nil), mirroring Reenrich/SearchSource — the anti-corruption seam keeps api free of enrich imports (INV2).
- The answer: 200 `{id, purpose, plan: [{method, url, headers, body(base64), binary_safe, timeout_seconds, min_interval_ms}]}` — the descriptor verbatim from the store, fully substituted, nothing re-shaped handler-side; 204 when nothing is claimable.
- Swag annotations ride the handler (the enrich_admin.go pattern); regen is the closeout task's job, not this one's.

## Acceptance

- The duty exits 0: claim handler tests green, the route present in router.go.
- Tests assert: descriptor fields verbatim from a seeded job, 204 on an empty queue, and the browse group's role posture (unauthenticated 401, client token accepted, the handler reachable with a device token).

## Constraints

- api stays pure delegation: zero enrich/plugin imports; the descriptor types are api-local unexported structs (the export-budget posture of SourceInventory).
- No new exported api symbols beyond the Deps field.
