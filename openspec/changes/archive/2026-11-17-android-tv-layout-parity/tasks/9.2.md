## Goal

cycles the pick within the served plan's pick space, and the controls' info
blocks list the served labels. `selectVoiceover` (PlayerOrchestration.kt:209)
gains its first UI caller.

## Cycle law

- pick space: SingleVariant(voiceovers = n) → n picks; Rendition → the served
  voiceover count AVAILABLE at pick time via the session-side carrier (read
  the earlier «carried at plan build» as «available at pick time» —
  RenditionPlan.from's second arg exists at the call but is dropped for
  Rendition: Playback.kt:84 keeps Rendition a bare data object and
  RenditionPlanTest:39–40 pins it bare, so the count lives on the session
  carrier, never in the plan — state/Playback.kt stays untouched);
  NoPicker or n = 0 → a fail-open no-op (no toast, no state change)
- the pick wraps: (current + 1) mod n; current starts at the launch-leg
  default 0, tracked on the Active session
- the act calls the existing selectVoiceover(next) — the k+1 track mapping in
  Media3Controller is untouched
