# 1.1 Layout rule on TOTAL audio — the discriminator stops keying on sidecars

## Goal

A source carrying more than one audio stream (embedded plus resolvable
sidecars) publishes the RENDITION layout; a single audio stream keeps the
single-variant degenerate exactly as today. The embedded-audio count is
discovered at build time from the original file itself — the red repro
(`TestPackMultiAudioRenditionLayout`, facts carrying NO streams array)
turns green.
